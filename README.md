# 超声图像校正程序：v01–v29

本仓库按目录保存超声图像校正程序的历史快照及重新编号的交付版。每个版本位于 [`versions/`](versions/) 下独立的 `v01`–`v29` 文件夹；主要变化见 [版本特性表](VERSIONS.md)。v27 历史目录保留作溯源；此前交付的 v27/v28 程序包已按用户更正分别命名为 v28/v29。

可直接下载的完整程序包：[v28.zip](packages/v28.zip) · [v29.zip](packages/v29.zip)。两包均只含程序、配置、测试和说明，不含患者图像或原始采集数据。

## 版本来源与范围

- `v02`–`v27` 来自本机 `D:\Tim\Lab\Program` 中对应编号的已生成程序包。
- `v28` 是此前误标为 v27 的 Lee＋双边滤波交付版；`v27` 历史目录仍保留，不作为本次交付包。
- `v29` 是此前误标为 v28 的方向自适应边缘增强及实时预览优化版；两版压缩包均与当前源码一致。
- `v01` 来自时间早于 v2 的未编号 `UltrasoundBinCorrection_Auto_2D` 程序包，**“v1”是本仓库为整理顺序所作的推定编号**，不是原包的正式名称。
- 独立的视频工具、单独编号的三维工具、ROI 标注工具，以及更早的未编号试验包不属于这 27 个主线版本。
- v26 原包的内层目录及文档标题仍写着“v25”；本仓库按**外层压缩包 `UltrasoundImageCorrection_Image_v26_LeeBilateral.zip`** 认定其为 v26，并保留原文件内容。

## 使用

选择所需版本目录，先阅读其中的 `使用说明.md` 和 `requirements.txt`。建议为该版本创建独立 Python 环境，并在该目录安装依赖后运行 `python ultrasound_bin_gui.py`。v17–v20 另有 `ultrasound_3d_viewer.py`。

历史 `.bat`、`.code-workspace` 和 `.vscode` 文件是原版随附配置，其中部分写死了原电脑的 Python 路径；在其他电脑运行时请改用本机解释器或调整配置。v24 的 U-Net 功能需要另行安装 `requirements-ml.txt` 中的可选依赖并提供模型权重；仓库不含训练权重。

仓库只包含程序源码、启动配置、依赖清单、说明、代码差异补丁和 v28/v29 的源码压缩包。**不包含**原始 `.bin`、采集元数据、患者/胎儿图像、对比 PNG、模型权重或缓存文件。处理效果须用你自己的合法数据验证；标注结果不应直接用于医学诊断。

本仓库未附加开源许可证；上传到 GitHub 不代表授予第三方复制、修改或再发布许可。
