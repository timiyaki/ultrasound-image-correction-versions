# 超声图像程序包

本仓库保存 `D:\Tim\Lab\Program` 中的 42 个完整 ZIP 程序包。它们是交付压缩包的原样副本，优先于仓库旧版的源码摘录；旧源码目录已由这些程序包替换。各版本用途见 [版本索引](VERSIONS.md)。

- [v1–v37 程序包](packages/)：按 `v数字_版本名称.zip` 命名。其中 v1 是二维校正主线的推定早期编号；另有独立、未编号的 ROI 标注工具。
- [无编号早期程序包](VERSIONS.md#无编号程序包)：按用户要求保留原名，不擅自补版本号。

部分原包包含用于展示处理效果的超声 PNG，以及 Python 缓存文件；没有发现原始 `.bin` 或 `.snp` 采集文件。仓库目前公开可访问；部分历史程序包包含超声 PNG，请复核这些图片的使用权限。各版启动文件可能包含当时电脑的 Python 路径，换电脑运行时应检查环境配置。

程序及自动标注结果仅供图像处理研究与展示，不用于医学诊断。本仓库没有附加开源许可证。
