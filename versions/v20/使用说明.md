# 超声图像灰度校正工具 Image v20

## 安装与启动

### 推荐：直接使用已配置的 VS Code 工作区

1. 双击 `UltrasoundBinCorrection.code-workspace`，用 VS Code 打开。
2. 状态栏应显示配置好的 Python 解释器，而不是 `C:\Python314\python.exe`。
3. 打开“运行和调试”，选择“运行超声 BIN 校正工具”，按 F5。

项目已固定使用：

```text
C:\Users\timiy\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe
```

该解释器已包含 NumPy、Pillow 和 tkinter，不需要联网安装依赖。

如果 VS Code 仍显示 Python 3.14：按 `Ctrl+Shift+P`，运行“Python: Select Interpreter”，选择“Enter interpreter path”，粘贴上面的完整路径。

### 普通 Python 环境

1. 安装 Python 3.10 或更高版本，并勾选“Add Python to PATH”。
2. 在本文件夹打开命令行，运行：

   ```text
   python -m pip install -r requirements.txt
   ```

3. 双击 `启动超声校正工具.bat`，或运行：

   ```text
   python ultrasound_bin_gui.py
   ```

## 使用步骤

1. 点击“采集目录”的“浏览”，选择同时包含以下文件的目录：

   ```text
   raw_frames_u8.bin
   frames.json
   scan.snp
   integrity.json
   ```

   也可以选择它们的上级目录；如果只发现一组数据，程序会自动定位对应的 `source` 文件夹。
2. 程序自动读取探头型号、帧数、扫描线数、采样点数、扫描角、死区半径、采样尺度及 `scan.snp` 中的深度、频率、增益和动态范围，并用 `integrity.json` 校验文件长度和 SHA-256。
3. DSC参数将自动填入并启用，程序随后自动载入全部帧和生成四宫格预览，不需要再点击载入按钮。用底部滑块检查全部帧。
4. 点击“自动（整组统一）”。程序会分析组内全部图像，再计算一套稳健的共享参数；所有图像都使用这套参数。界面同时保留“保守、推荐、增强”三组快捷参数。
5. 点击“处理并导出”。程序输出：
   - 校正后的无头 `uint8 .bin`；
   - 每帧一张 PNG；启用红/蓝描边时PNG为RGB彩色图；
   - DSC转换后、调色前后的对比图；
   - 包含尺寸、参数和统计量的 JSON 文件。

左侧参数区域带有独立的垂直滚动条，并支持鼠标滚轮；“重新读取并预览”和“处理并导出”按钮固定在左下方，不随参数区域滚动。

## 四宫格实时单帧预览

右侧预览固定分为四个区域：

- 左上：原始扫描线图像；
- 右上：只完成DSC几何校正；
- 左下：DSC校正、去噪和统一调色后的灰度图；
- 右下：DSC校正、调色、红/蓝亮区描边及可选绿色主体边界。关闭所有描边选项时，该区域与左下相同。

以下参数使用滑动条调节，并在右侧校正图像中实时预览：

- α 对比度增益
- β 亮度偏移
- γ Gamma
- 噪声百分位
- 原始细节混合
- 去散斑/去噪强度
- 边缘清晰度增强
- 红色整体区域阈值、蓝色强反声阈值与连续扩散次数（启用描边后）
- 主体扩散次数和画笔大小（启用主体识别后）
- 骨骼声影补偿强度（启用补偿后）

选择采集目录或点击“读取目录参数”后，程序会自动载入序列并渲染当前帧，无需点击预览按钮。完成整组自动分析后，所有帧共享同一套参数；切换帧时滑动条保持不变。调整α、β、γ、去噪、边缘、红/蓝描边、黑电平、白点或DSC参数时，四个区域会自动刷新。快速连续拖动会合并为最后一次更新，避免界面卡顿。

实时预览的白点和噪声方差也从整组图像统一标定，因此当前帧预览与最终整组导出的灰度尺度一致。

“重新读取并预览”用于文件内容发生变化时重新读取数据。程序会记住当前帧号；只要新序列包含该帧，重新读取后不会跳回第一张。如果新序列帧数较少，则保留到它能显示的最后一帧。

只有点击“处理并导出”时，程序才用当前这套统一参数处理完整序列，并生成BIN、PNG、对比图和记录共享参数的JSON。噪声方差与白点也从整组代表帧统一估计，不会逐帧改变隐藏的归一化尺度。

导出的对比图不会显示原始“扫描线×采样点”矩形图。左侧是只完成DSC几何转换、尚未调色的扇形图像；右侧是同一帧完成统一调色、主体增强、边缘增强及可选声影补偿后的结果。文件名为 `raw_frames_u8_dsc_tone_before_after.png`。

## 整组统一自动校正

“自动（整组统一）”会先分析全部图像的主体、灰度与噪声，再用中位数和较高噪声分位合成一套共享参数。个别过亮、过暗或噪声较大的帧不会单独改变参数；切换帧时α、β、γ等滑动条保持不变。自动计算遵循以下约束：

- 在原始扫描线数据中估计胎儿/组织主体区域，降低暗液区和空背景对调色决策的影响；
- 主体区域使用更高的中灰、高灰目标，使胎儿结构比周围暗区更突出；
- 只统计有效扫描像素，扫描区外的纯黑背景不参与白点估计；
- 高光控制在接近白色但不形成大片纯白饱和；
- 暗部保持黑色，避免整体抬升后发灰；
- 高对比自动模式使用α=1.08–1.20、β=6–18，并在γ=1.55–1.95范围内选择；
- 即使β为正，原始零值仍被强制锁定为输出0，不会把黑背景抬成灰色；
- 使用5×5 Lee滤波和第二级边缘感知去散斑；噪声百分位自动取25–38，去散斑/去噪强度约0.68–0.86，并只混回约18%–28%的原始细节；
- 第二级去散斑在均匀区加强平滑，在连续强轮廓处保留变化，避免把组织边缘一并抹除；
- DSC转换后进行受限多尺度边缘增强，自动强度约1.70–1.90；以细尺度轮廓为主，抑制真轮廓旁边的暗侧残影和重复边缘；
- 增强结果受局部3×3真实灰度范围约束，避免产生原图中不存在的明显亮边或暗带；
- 保留亮组织内部的中灰区域和细小、不连通灰度结构；
- 自动参数采用主体加权的受限搜索，在提高胎儿亮度和对比度的同时限制大面积饱和。

自动按钮只保存一套黑电平、白点百分位、α、β、γ、Lee窗口、噪声百分位、原始细节混合、去散斑/去噪强度、主体边界增强及声影补偿强度。手动调整滑动条会更新整组共享设置；导出时所有图像严格使用同一套参数。

## 红色整体区域与蓝色强反声描边

“启用红色整体区域＋蓝色强反声描边”默认开启。右下预览、逐帧PNG以及调色前后对比图会用红色细线标出整体亮区，用蓝色细线标出其中灰度更高的强反声区域。该功能属于可视化叠加层，不会改变校正后的灰度BIN数据。

- **整体区域阈值（红）**：灰度达到该值附近的组织归入整体亮区，滑动条下界已降至80，默认150；推荐120–180。阈值越低，红线覆盖的组织范围越大。
- **强反声阈值（蓝）**：灰度达到较高阈值的区域归入强反声区，默认225；推荐210–240。若该值低于红色阈值，程序会自动确保蓝色阈值至少比红色阈值高1级。

## 体素曲面三维重建与联动切片（Image v20）

读取采集目录后，点击主窗口底部的“**三维重建（红色区域＋蓝色强反声高亮）**”。新窗口会继承主窗口当前的统一调色参数、红色阈值、蓝色阈值和连续扩散次数，无需再次设置。

三维坐标由以下信息共同确定：

- 单帧内部使用 `scanAngle`、`deadRadius`、`sampleScale` 和扫描线/采样点位置恢复扇扫几何；
- 帧间优先逐帧读取 `frames.json` 中的 `angle3D` 旋转叠加；
- 如果没有有效的 `angle3D`，才按照总帧数和“备用扫描总角度”均匀分配角度；
- 红色连续曲面表示整体标注体；蓝色连续曲面表示体内强反声结构，并优先高亮显示。

三维窗口支持鼠标左键拖动旋转、滚轮缩放、自动旋转、重置视角和保存当前视图。左下角的 X（红）、Y（绿）、Z（蓝）方向轴会随模型视角同步旋转，用于确认当前观察方向。

“连续帧间填充切片”会先在两帧真实采集之间生成虚拟采样。默认填充2层，并使用“单调曲度”模式执行带斜率限制的三次 Hermite 插值：它沿相邻帧趋势形成平滑曲率，同时不会像普通三次插值一样在亮区边界产生过冲和不自然鼓包；也可以选择“线性平均”。

虚拟采样不会直接作为薄片显示。程序会把全部采样重新投影到规则三维体素空间，执行三维封闭、邻域扩散和曲率平滑，再提取连续外表面。因此侧视图不再由一层层帧平面组成。

- **体素分辨率**：默认144。提高到160或176可获得更细致的曲面，但会增加内存和重建时间；快速检查可使用112或128。
- **体曲面平滑**：默认3。推荐2–4；数值过高可能把距离很近的独立结构连接起来。

三维结果生成后会自动打开联动切片窗口：

- 左侧显示经过 DSC 校正与统一调色、但没有彩色标线的图像；
- 右侧显示同一帧叠加红色整体区域和蓝色强反声区域后的图像；
- 可拖动底部滑块或点击上一帧/下一帧；
- 三维窗口会用黄色扇形边界及黄色截面点同步高亮当前帧，蓝色强反声仍保持蓝色。

调整红/蓝阈值、扩散次数、帧间填充或采样间隔后会自动重建。帧间隔、扫描线间隔和深度采样间隔越小，细节越多，但重建和旋转会更慢。

注意：该功能是基于二维灰度阈值的可视化重建，不等同于经标定的诊断级体积超声，也不能恢复声影遮挡后未采集到的真实组织结构。

### Image v20 性能模式

- 拖动、缩放和自动旋转期间最多使用约5.5万个曲面点和半分辨率快速预览；松开鼠标约140毫秒后恢复完整体素曲面质量。
- 三维红/蓝底图按视角缓存。切换帧时只更新黄色截面，不再重复投影整个点云。
- DSC切片复用已完成的去噪和调色结果，避免第二次运行完整滤波流程。
- 红/蓝切片标注使用预计算的DSC坐标查找表，并保留最近12个切片的显示缓存；连续拖动滑块时有55毫秒防抖。
- 连续帧填充只在真实采集帧上执行扩散，再插值区域概率；最终统一转为三维体素曲面，而不是渲染插值切片。
- **连续扩散次数**：分别对两级区域执行边缘受限的各向异性连续扩散，再提取轮廓。默认5次；提高可连接相邻的断续区域，但过高可能合并距离很近的不同区域。建议3–7次。
- 扩散由原灰度边缘控制：相近亮度之间可以连续传播，遇到明显暗边时会受到抑制。
- 红线为 `RGB(255,32,32)`，蓝线为 `RGB(32,112,255)`；两者均为1像素内侧边界。发生重叠时蓝线优先，以突出强反声。
- 如果不勾选该选项，右下预览和PNG继续保持普通灰度图。

## 自动主体识别与画笔标注

主体识别使用绿色细线 `RGB(40,255,80)` 显示，与红色整体亮区和蓝色强反声标线相互独立。

### 全自动识别

1. 将底部帧滑块移到主体结构较清楚的一帧。
2. 点击“自动识别主体（整组）”。
3. 程序从当前帧中央组织的灰度、纹理和空间位置建立初始种子，再沿连续扫描顺序向前、向后传播。
4. 完成后自动勾选“显示绿色主体边界”，切换帧即可检查传播结果。

启用主体识别后执行导出，程序还会建立 `raw_frames_u8_subject_masks` 文件夹，每帧保存一张黑白主体掩膜PNG，便于后续检查或分析；彩色校正PNG中同时保留绿色主体边界。

### 画笔辅助识别

1. 勾选“画笔标注模式（在左下图像拖动）”。
2. 在左下“DSC校正＋调色”图像的主体内部按住鼠标左键涂画；黄色笔迹表示正样本。
3. 鼠标右键可擦除笔迹，画笔大小可以用滑动条调节。
4. 松开鼠标后，程序会自动把标注扩散到当前主体，并传播到整组其他图像。也可以点击“按标注识别整组”重新运行。
5. 点击“清除标注/结果”可删除黄色笔迹和全部绿色主体边界。

主体扩散默认18次，建议12–24次。次数越高，当前帧从画笔种子向周围组织扩展得越远；过高可能把邻近组织合并为同一主体。

为减少图像边缘伪影，算法会重建有效扇区范围、收缩识别安全区，并在显示绿色边界时额外静默靠近扇区侧边和底边、约占图像短边7%的区域。边缘排除只影响主体识别，不影响原始灰度图和红/蓝亮区标线。

主体识别属于辅助可视化和序列跟踪，不是医学诊断分割，也不应作为病灶、器官或胎儿解剖结构的标注真值。

## 骨骼声影灰度补偿

该选项默认关闭。勾选“启用灰度补偿（仅用于显示）”后，程序会在原始扫描线方向检测强骨性回声及其后方的衰减带，并参考相邻扫描线进行有限的灰度抬升。

- 默认强度0.45，建议范围0.25–0.60；
- 只有“前方强回声、后方偏暗、相邻扫描线仍有回波”同时满足时才补偿；
- 补偿采用加法混合，不替换原始像素纹理；
- 强度1.0时单像素最多抬升42个灰度级，默认强度最多约19级；
- 原始零值和扫描区外背景保持不变；
- 参数JSON会记录检测比例、平均抬升量和最大抬升量。

重要：骨骼后方未采集到的真实解剖信息无法从灰度图恢复。该功能只是减轻声影的显示效果，不会生成可信的新组织结构，不应用于诊断、定量测量或标注真值。

## 参数说明

- **黑电平**：从原始灰度中减去的固定偏置；背景已经为 0 时保持 0。
- **白点百分位**：用于整个序列，整组自动模式也只生成一个统一值。推荐 99.5–99.9。
- **α 对比度增益**：控制灰度增益。α=1 不改变；α>1 增强对比度。推荐 1.00–1.25。
- **β 亮度偏移**：以 8 位灰度级为单位整体平移亮度。β=0 不改变；推荐 -10–10。
- **γ Gamma**：小于 1 提亮暗部和中间灰度，大于 1 压暗中间灰度。推荐 0.85–1.05。
- **Lee 窗口**：散斑滤波邻域。5×5 是推荐起点；窗口越大，平滑越强。
- **噪声百分位**：用于估计均匀区噪声方差。推荐 20–35。
- **原始细节混合**：滤波后混回的原始纹理比例。推荐 0.10–0.25。
- **去散斑/去噪强度**：控制Lee滤波后的边缘感知平滑比例。0为关闭第二级处理，1为最强；推荐0.55–0.80，过高会损失细弱纹理。
- **边缘清晰度增强**：在DSC转换后增强组织轮廓；程序会自动抑制暗侧光晕并限制局部过冲。手动推荐1.10–1.90，若仍看到重复轮廓可降至0.90–1.40。
- **整体区域阈值（红）**：决定整体亮区范围，下界80，推荐120–180。
- **强反声阈值（蓝）**：决定哪些高灰度区域按强反声显示，推荐210–240。
- **连续扩散次数**：控制两级断续轮廓的连接程度，推荐3–7。
- **画笔大小**：控制左下图像中黄色正样本笔迹的屏幕半径，推荐8–20。
- **主体扩散次数**：控制主体从自动或手动画笔种子向周围组织扩展的距离，推荐12–24。
- **骨骼声影补偿强度**：控制疑似骨后声影的有限灰度抬升。0为无补偿，推荐0.25–0.60；数值过大会降低声影这一真实声学现象的可见性。
- **导出时转置宽高**：只改变导出的图像和 BIN 维度顺序，不改变算法。

## DSC 数字扫描转换

DSC（Digital Scan Conversion）把按“扫描线 × 深度采样”存储的扇扫数据，从极坐标几何转换成普通笛卡尔图像。程序使用双线性插值：

```text
输入：[帧数, 扫描线数, 深度采样数]
输出：[帧数, DSC输出高度, DSC输出宽度]
```

参数参考：

| 参数 | 建议起点 | 说明 |
|---|---:|---|
| 启用DSC | 默认关闭 | 仅扇扫/凸阵扫描线数据开启；线阵图像不要开启 |
| 扇扫角 | 60° | 常见尝试范围 40°–90°，应以探头规格为准 |
| 起始半径 | 0 | 探头顶点到首个有效采样的距离，以采样点为单位 |
| 输出宽度 | 512 | 笛卡尔图像宽度 |
| 输出高度 | 512 | 笛卡尔图像高度 |

当前样例的 `96×512` 可解释为 96 条扫描线、每线 512 个深度采样。如果数据来自凸阵或机械扇扫，可从 `60°、起始半径0、输出512×512` 开始预览；如果图像几何过宽或过窄，应调整扇扫角。准确还原仍需要探头扇扫角和起始深度信息。

对于包含 `frames.json` 的采集目录，不再使用上述猜测值：程序会自动读取 `scanAngle`（弧度转角度）、`deadRadius`、`lineCount` 和 `sampleCount`。本次样例自动读取到探头 `SS-6D`、扫描角约 `82.5°`、死区半径40、96条扫描线和512个深度采样。

## 当前样例文件

对 `raw_frames_u8.bin`，已验证的存储布局为：

```text
77 帧 × 96 行 × 512 列，uint8，无文件头
```

灰度校正公式为：

```text
y = 255 × clip(αx + β/255, 0, 1)^γ
```

其中 `x` 是完成黑电平、Lee滤波及白点归一化后的0–1灰度；整组自动模式下，每帧拥有自己的白点与曲线参数。

建议起始参数：黑电平 0、白点 P99.8、α=1.10、β=0、γ=0.92、Lee 5×5、噪声百分位 25、原始细节混合 0.15。

三组参考值：

| 模式 | α | β | γ | 用途 |
|---|---:|---:|---:|---|
| 保守 | 1.00 | 0 | 1.00 | 保留原始灰度关系，适合测量和分割 |
| 推荐 | 1.10 | 0 | 0.92 | 适度增强对比度并提亮中间灰度 |
| 增强 | 1.20 | 5 | 0.85 | 暗图显示和演示，不建议用于定量测量 |

## 注意事项

本程序处理的是已经形成的 B-mode 灰度图，不是 RF/IQ 通道数据。没有采样率、探头中心频率和标定数据时，不执行 RF 带通、Hilbert 包络、阵元延迟校正或物理 TGC。若要进行定量回波强度或组织参数分析，应保留原始文件，并使用设备标定信息重新处理。
