# 超声二维论文式图组工具 Image v25

本版本把原有的超声灰度校正流程整理为可直接比较的二维图组。它只包含经典二维图像处理，不包含三维成像，也不包含 U-Net、YOLO、SegFormer 或其他机器学习模块。

## 启动

双击 `启动超声校正工具.bat`。也可以打开 `UltrasoundBinCorrection.code-workspace`，在 VS Code 中按 F5。

程序已配置使用：

```text
C:\Users\timiy\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe
```

## 读取数据

点击“采集目录”的“浏览”，选择包含以下文件的目录：

```text
raw_frames_u8.bin
frames.json
scan.snp
integrity.json
```

程序会自动读取帧数、扫描线数、采样点数、扫描角度、死区半径和探头信息，并完成 DSC 数字扫描转换。如果只选择上级目录，程序在只发现一组完整数据时会自动进入对应的 `source` 目录。

## 处理流程

二维处理链为：

```text
扫描线灰度帧 → 对数域Lee → SVD低秩块组 → Hessian结构滤波 → PFDTV边缘保持 → DSC → α/β/γ灰度校正 → 边缘增强 → 可选回声描边
```

“自动（整组统一）”会分析代表帧，为整个序列选择同一套参数。这样不同帧的灰度关系仍然可以直接比较。右侧四宫格实时显示原始扫描线、DSC原图、校正图和描边图。

常用参数：

- α：对比度增益；推荐 1.05–1.25。
- β：亮度偏移；推荐 0–15。
- γ：中间灰度曲线；本程序公式中 γ 大于1会压暗中间灰度，推荐 1.45–1.90 用于提高黑白分离。
- 去散斑强度：推荐 0.60–0.85。
- 原始细节混合：推荐 0.15–0.28；过低会损失细弱纹理。
- 边缘增强：推荐 1.20–1.90；过高可能出现重复轮廓。
- 红色阈值：整体较亮组织范围；自动标注限制在 60–90，手动可在 40–240 内微调。
- 蓝色阈值：强反声范围；自动标注限制在 160–180，手动可在 128–255 内微调。

## 三篇论文对应的滤波模块

三个模块都在左侧“论文去散斑与结构滤波（均可调）”区域。强度设为0即可单独关闭，适合逐项比较。

### SVD低秩块组去散斑

依据《Despeckling of Ultrasound Images Using Block Matching and SVD in Sparse Representation》的对数域、相似块组、SVD和奇异值软阈值思路：

- 强度：0–1，建议0.20–0.40；数值越高，低秩约束越强。
- 块大小：5或7。论文实验中噪声标准差不高于0.5时5×5较合适，更高噪声可使用7×7。
- 软件使用局部块组代替论文中计算量很大的SLIC＋互信息全搜索，以保证实时预览；因此属于适配8位B-mode数据的CPU版本，不是作者源代码的逐位复现。

### Hessian结构自适应滤波

依据《Ultrasound Image Enhancement Using Structure-Based Filtering》的Hessian特征分类和异构滤波池：

- 使用论文阈值β=0.12、α=0.45区分均匀区、线/边界、斑点和未知区域。
- 线和边界沿Hessian次特征向量执行9点一维高斯滤波；斑点使用二维高斯；均匀和未知区域使用9×9中值滤波。
- 强度：0–1，建议0.35–0.60。
- 次数：1–3，普通超声推荐2次。论文指出第3次最平滑，但可能消除薄边缘和小斑点。

### PFDTV边缘保持滤波

依据《Phase Asymmetry Ultrasound Despeckling With Fractional Anisotropic Diffusion and Total Variation》的边缘显著性、自适应分数阶、各向异性扩散和总变分组合：

- 强度：0–1，建议0.25–0.50。
- 迭代次数：1–12，论文推荐8次。
- k0：5–60；建议20。较大值去噪更强但更容易损伤细节；论文给出的实际图像较佳范围为20–40。
- 时间步长固定为论文推荐的0.15。
- 软件使用稳定的离散多尺度边缘显著性近似，保持8位图像实时调节能力；不是论文完整Cauchy相位不对称和G-L长程分数阶算子的逐位复现。

三个模块之后会按边缘显著性有限混回连贯轮廓残差，使弱边界不会随强去散斑一起消失；孤立散斑不会直接混回。最终仍可用“边缘清晰度增强”控制DSC域轮廓强度。

## 整组自动分析与防涂抹

点击“自动（整组分析＋防涂抹）”后，程序不会简单把去噪滑块统一调高，而是执行以下步骤：

1. 快速分析全部帧的对数域散斑残差、动态范围、细节密度、弱边界和强边界；
2. 从整组中均匀抽取代表帧，实际试处理3套SVD、结构滤波和PFDTV候选参数；
3. 比较均匀区散斑残留，同时惩罚强边界损失、弱边界损失、细节相关性下降和过度锐化；
4. 使用最多10张代表帧计算统一的α、β、γ、黑白点和边缘增强参数；
5. 再用6张代表帧检查高光饱和比例和暗部灰阶。如果存在明显过曝或黑部抬灰，会降低α/β并提高白点百分位；
6. 复用同一批处理结果计算红、蓝自动标注阈值：红线限定为60–90，蓝线限定为160–180，不额外重复滤波；
7. 最终参数回填到原来的所有滑块和下拉框。自动完成后仍可继续手动微调，手动值会作为整组统一设置用于预览和导出。

自动模式的目标不是得到最平滑的图，而是在额外降低均匀区散斑的同时保持连贯边界。处理参数JSON中的 `automatic_group_optimization` 会记录整组统计、所有候选分数、边缘保留比例、细节相关性和高光检查结果，便于复核。

性能方面，SVD与Hessian结构滤波会在多帧处理时使用最多4个受控工作线程；噪声、白点和自动参数分析减少了重复采样。单帧实时预览仍只处理当前帧，切换帧时不会重新分析整组。

## 二维图组输出

点击“处理并导出二维图组”后，输出目录包含：

1. 校正后的 `uint8 .bin`；
2. 每帧二维 PNG；
3. 传统调色前后对比图；
4. `raw_frames_u8_二维图组` 文件夹；
5. 处理参数 JSON。

图组文件夹中包含两类结果。

### 单帧六联图

从序列均匀选取最多6个代表帧，每帧生成一张2×3图组：

```text
(a) DSC原图          (b) 去散斑          (c) 灰度校正
(d) 边缘增强         (e) 回声描边        (f) 同一区域处理前/后放大
```

黄色框表示自动选择的高信息量局部区域；第(f)幅保持相同裁剪和缩放，便于观察散斑、弱灰度结构与边缘是否被保留。

### 跨帧三行总览

对相同的代表帧按列排列：

```text
第一行：DSC原图
第二行：二维校正结果
第三行：红/蓝回声描边结果
```

每一列始终对应同一帧，避免因帧号或裁剪不同造成误判。`图组说明.json` 记录代表帧号、面板含义和输出文件路径。

## 论文组图设计参考

- Phase Asymmetry Ultrasound Despeckling With Fractional Anisotropic Diffusion and Total Variation：使用原图、多种滤波结果、局部ROI与同一扫描线灰度剖面进行并列比较。https://pmc.ncbi.nlm.nih.gov/articles/PMC7370834/
- Ultrasound Image Enhancement Using Structure-Based Filtering：把原始图与第1、2、3次滤波结果按固定顺序排列，并指出过度滤波会丢失薄边缘和小亮点。https://pmc.ncbi.nlm.nih.gov/articles/PMC4089207/
- Despeckling of Ultrasound Images Using Block Matching and SVD in Sparse Representation：同时展示输入、去散斑结果和误差/局部细节，强调所有方法使用相同ROI比较。https://pmc.ncbi.nlm.nih.gov/articles/PMC9321351/

本软件借鉴的是“固定帧、固定裁剪、处理阶段有序排列”的比较方法，没有复制论文图片或复现论文专有算法。

## 使用限制

本程序处理的是已经形成的8位B-mode灰度帧，不是RF/IQ通道数据。描边和主体边界是规则式图像处理结果，不是解剖分割真值。骨骼声影补偿只能改善显示，不能恢复未采集到的真实组织信息。软件及图组不用于医学诊断。
