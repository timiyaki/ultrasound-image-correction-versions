# Image v25 精简双算法版

解压整个文件夹后，双击 `start.bat`。当前电脑优先使用已有、包含 NumPy/Pillow/Tkinter 的 Python；如安装了本文件夹内的 `.venv` 则优先使用它。VS Code 可打开附带的工作区文件运行。

## 图像处理链

目录读取 → 黑位校正与对数变换 → 自适应 Lee 去散斑 → 单次双边滤波 → 原始细节混合与逆对数 → 共同白点归一化 → α/β/γ → 可选声影显示补偿 → DSC 扇扫结构校正 → 抗光晕边缘增强 → 可选红蓝描边。

去散斑仅使用 Lee，滤波仅使用双边滤波。已移除 SVD、Hessian 滤波池、PFDTV、相位残差回填及额外残差去噪。边缘增强作为独立显示增强步骤保留；标注扩散仅生成轮廓，不再次去噪图像。

## 两种算法与参考参数

| 项目 | 默认值 | 作用 |
|---|---:|---|
| Lee 去散斑强度 | 0.60 | 0 关闭，越大越接近完整 Lee 结果 |
| Lee 窗口 | 5 | 可选 3/5/7/9；较大的邻域更容易损失细节 |
| 噪声百分位 | 25 | 从局部方差估计整组共同噪声方差 |
| 双边滤波强度 | 0.45 | 0 关闭；控制原输入与滤波结果的混合 |
| 双边邻域半径 | 2 | 对应 5×5；可选 1/2/3，对应 3×3/5×5/7×7 |
| 灰度相似尺度 | 0.08 | 归一化 log 域中的尺度；越小越少跨明暗边界平滑 |
| 原始细节混合 | 0.15 | 越大越接近原图，也可能带回散斑 |

双边滤波的空间尺度由邻域半径确定，且只执行一遍。两个强度均为 0 时不执行去散斑和滤波，后续调色、DSC、增强仍按各自设置执行。

α/β/γ 保留实时滑块，公式为 `y = 255 * clip(alpha*x + beta/255, 0, 1)^gamma`，其中 x 是共同白点归一化后的强度。参考起点为 α=1.10、β=0、γ=0.92；不同采集应先使用整组自动建议，再按视觉效果微调。

## 保留的功能

- 浏览采集目录，读取 raw_frames_u8.bin、frames.json、scan.snp 和 integrity.json。
- DSC 扇扫结构校正、白点/黑位、灰度增强和抗光晕边缘增强。
- 整组自动分析并比较三套 Lee/双边滤波候选，以散斑残留、强弱边界和细节保留评分；随后检查共同调色参数的高光与暗部。所有帧使用同一套参数。
- 红蓝自动标注独立于调色自动按钮：红线自动参考 60–90，蓝线 160–180；均保留手动滑块。
- 四宫格、当前帧实时预览、切换帧沿用统一参数、重新载入保留帧号。
- 原有主体画笔/种子扩散、可选声影显示补偿。
- 处理后 BIN、逐帧 PNG、DSC 调色前后及标注对比、论文式组图与参数 JSON 导出。新增参数记录仅包含 Lee 和双边滤波配置。

本版本不含机器学习和三维成像。旧版本参数中 SVD/Hessian/PFDTV 字段不再适用，请在此版本重新自动估计。原始采集文件不会被修改。
