# 超声图像灰度校正工具 Image v23

这是独立的二维 DSC 校正、调色和标注程序，不再包含三维成像入口。

## 启动

- 最简单：双击 `启动超声校正工具.bat`。
- VS Code：双击 `UltrasoundImageCorrection.code-workspace`，按 F5，选择“运行二维超声校正 Image v23”。
- 也可运行 `python ultrasound_bin_gui.py`。

程序已经指向电脑上现有的 Python 环境，并检查 NumPy、Pillow 和 tkinter。

## 保留的 Image v16 基本功能

- 浏览一个采集目录，自动读取 `raw_frames_u8.bin`、`frames.json`、`scan.snp`、`integrity.json`。
- 自动读取帧数、扫描线数、采样点、探头、扇扫角、死区半径、采样尺度和逐帧扫描角。
- 四宫格实时预览：原图、DSC、DSC＋调色、DSC＋调色＋标注。
- 整组使用同一套 α、β、γ、白点、去散斑、原始细节混合和边缘参数。
- 红色整体亮区、蓝色强反声区、绿色主体边界。
- 自动主体识别、鼠标画笔标注及向连续帧传播。
- 骨骼声影显示补偿、PNG/BIN/参数 JSON 和 DSC 调色前后对比图导出。

## Image v21–v23 改进

### 真轮廓旁残影

旧版宽尺度锐化会在真边缘旁形成明暗成对的轮廓。v21 改为单侧脊线增强：

1. 96% 细尺度、4% 宽尺度，仅用宽尺度维持连续性；
2. 只增强局部主亮脊，暗侧波瓣保留 6%；
3. 用平滑梯度判断连续轮廓，孤立散斑不会获得完整锐化；
4. 增强后限制在原始 3×3 邻域附近，最大外扩灰度由 7 降到 4。

自动边缘强度范围改为 1.45–1.65。样例第39帧中，锐化造成的暗侧变化像素从12,207降到87，约减少99.3%。

### 胎儿与子宫壁区分

- DSC 后对中央组织做很小的局部对比提升，保留内部不连通的灰色区域。
- 只压低扇区外围、明显高于邻域的反声亮斑，单像素最多降低16级；不删除子宫壁，也不修改原始文件。
- 主体自动种子增加中央位置权重并收紧到高可信区域，避免从外围子宫壁开始扩散。
- 主体扩散现在受灰度边缘控制；遇到胎儿与子宫壁接触处的强反射线会停止跨越，而不是仅凭相似灰度继续向子宫壁扩散。
- 绿色主体边界在左右两侧会搜索当前位置附近的连续高亮脊线，并吸附到最可信的强反射线；搜索半径受到限制，不会跳到远处的亮壁。
- 主体边界使用向内两像素显示，提高与红色、蓝色标线同时出现时的可辨认度。

### 标注避开边缘亮斑

- 红、蓝标线会忽略扇区外围约5.5%范围中的紧凑强反声亮斑。
- 绿色主体识别使用更保守的约9%外围安全带，并排除强反声亮斑。
- 安全带截断形成的边界不会被画成绿色，避免把子宫壁或扇区边界误当主体轮廓。

这些规则只影响显示增强和标线；校正后的灰度内容仍被保留。自动结果不是医学诊断分割，必要时请用画笔提供胎儿正样本。

## 三列导出对比图

导出的 `raw_frames_u8_original_tone_annotated.png` 固定使用同一几何位置的三列：

1. DSC原图：只完成几何转换，未进行调色；
2. 调色后：去散斑、灰度校正和轮廓增强后的纯灰度图；
3. 标注后：在调色图上叠加红色整体亮区、蓝色强反声区及可选绿色胎儿主体边界。

三列不会把原始扫描线矩形与扇形图混在一起，便于逐帧直接比较。

## 独立自动标注

红/蓝描边区域新增“自动标注阈值（不改变调色）”按钮。它与“自动（整组统一）”灰度校正完全分开，不会修改 α、β、γ、白点、去噪、原始细节混合或边缘增强。

- 红线只在80–120范围内搜索。程序综合区域覆盖率、相邻像素连通度和孤立点比例，使整体亮区尽量连续，同时避免吞没整个扫描扇区。
- 蓝线只在180–220范围内搜索。程序把有效扫描区约5%左右的最高亮度作为目标，使强反声区域作为独立高亮区域显示。
- 最多抽取12张代表帧计算，因此整组图像使用同一组红、蓝阈值。
- 自动完成后，结果会写回原来的两个阈值滑块；所有手动滑块继续保留，可以在自动结果基础上实时微调。
- 连续扩散次数仍由原滑块控制，自动标注不会覆盖用户设置。

## 建议参数

点击“自动（整组统一）”作为起点。手动调整时建议：

- α：1.08–1.20
- β：6–18
- γ：1.55–1.95
- 去散斑：0.68–0.86
- 原始细节混合：0.18–0.28
- 边缘清晰度：1.20–1.65；仍有残影时先降到1.10–1.35
- 红线阈值：120–180
- 蓝线阈值：210–240
- 连续扩散：3–7
- 主体扩散：12–24

注意：显示增强和主体标注不可替代临床诊断或人工复核。
