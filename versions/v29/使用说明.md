# 超声图像灰度校正工具 Image v29：edgeEnhance-0913 边缘增强

本版从 Image v28 派生。保留原有采集目录读取、DSC、Lee 去散斑、单次双边滤波、α/β/γ 调色、整组自动参数、子宫壁分离、主体画笔及红蓝标注、预览和导出。只替换原有的“单侧亮脊”边缘增强算法；v28 原始说明见 `v28_原始说明.md`。

## 新的边缘增强

依据用户提供的 `edgeEnhance-0913.zip` 中 `extract_main_boundary.m` 的增强路径，以及 `edgeEnhanceApp.m` 的默认预设，移植为 `edge_enhance_0913.py`：

1. 对调色及 DSC 后的图像轻度高斯预平滑，用梯度结构张量估计每个像素的轮廓法向、方向一致性和梯度能量。
2. 用 16 个方向的线状高斯核，沿轮廓切向平滑，再用法向的负侧瓣/正中心核拉开边界对比；相邻方向线性混合，避免方向档位造成块状跳变。
3. 由梯度能量和方向一致性计算置信度，再经 `AlphaLo`–`AlphaHi` 的 smoothstep 软死区形成增强权重。以原图为背景，权重为 0 的像素保持不变。
4. “边缘增强”滑块控制总强度，0 为关闭，1.0 对应该 MATLAB 界面默认强度。自动模式根据噪声估计选择约 0.85–1.10 的较温和强度。

固定参数采用 0913 界面默认值：预平滑 σ=1，结构张量半径 3/方差尺度 2，`EdgeC=2.5`，`CohMin=0.30`，`AlphaLo=0.15`，`AlphaHi=0.50`；切向核半径 2、方差 2、2 次；法向核半径 2、方差 3、`EefPerp=2`、1 次；方向数 16。源算法的行坐标方向采用 0913 版的正号写法，不使用后来 `edgeEnhance.zip` 的翻转写法。

0913 包里的独立大边界提取、额外 Gamma 和“压暗羊水”节点曲线**没有**并入此程序：原程序已有自己的主体/红蓝标注和 α/β/γ 调色，重复接入会改变这两部分的行为。这个移植保留算法结构及默认参数，但由于 MATLAB 与 NumPy 的边界填充、梯度和插值实现不同，并非逐像素复现。

## 运行

双击 `启动超声校正工具.bat`，或在 VS Code 打开 `UltrasoundImageCorrection.code-workspace` 并按 F5。也可在安装 `requirements.txt` 依赖的 Python 环境中运行 `python ultrasound_bin_gui.py`。旧版启动配置含本机 Python 路径，在其他电脑应改为自己的解释器。

## 实时预览与性能

载入图像后拖动滑块，当前帧的四宫格会自动更新，无需再点击“载入并预览”。程序复用整组噪声估计、当前帧滤波和边缘响应；连续拖动时只保留最新预览任务，避免旧任务排队。切换帧后会以相同参数处理新帧。

默认边缘预览按最长边 512 px 计算边缘响应，再映射回原尺寸，以提升滑动流畅度。需要逐像素核对时，可勾选“精确边缘预览”；无论该选项如何，导出始终使用全分辨率算法，所以快速预览与导出可能有轻微差异。Lee 窗口或双边滤波等参数改变时仍需重新滤波，更新会比单独调整边缘增强慢。

边缘增强仍在 DSC 与调色后运行。若发现轮廓两侧出现亮/暗侧瓣，请先降低边缘增强强度；0913 法向核本身是双侧锐化，不具有 v28 单侧亮脊算法的抗重影限制。程序仅作图像显示与研究，不用于医学诊断。
