# 超声图像灰度校正工具 Image v28

本版直接在用户提供的 v21 压缩包代码上局部修改，保留原目录读取、DSC、四宫格、α/β/γ、主体识别、画笔传播、子宫壁分离、红蓝标注和导出逻辑。

## v28 去散斑与滤波

只使用一种去散斑算法（自适应 Lee）和一种滤波算法（单次 5×5 双边滤波）。替换 v21 的额外残差平滑，没有叠加 SVD、Hessian 或 PFDTV。

- Lee 在对数灰度域处理，局部统计排除无效零值；噪声估计优先采用非边缘区，减少把真实轮廓当作噪声。
- 双边滤波根据空间距离和灰度差决定权重，跨明暗边界的平滑量较小；无效黑区不参与滤波。
- 去散斑和双边滤波分别有强度滑块，设为 0 可单独关闭。双边相似尺度越小，越少混合不同亮度的组织。
- 保留原 α/β/γ 公式与单侧脊线增强，整组自动模式新增共同白点下的亮部限幅估计，尽量保留亮区中的灰色细节。
- 原有子宫壁分离和主体标注规则不变。原始数据不修改。

完整链路：黑位/对数变换 → Lee → 单次双边滤波 → 原始细节混合/逆对数 → 共同白点及 α/β/γ → 可选声影显示补偿 → DSC → 原 v21 子宫壁分离 → 原 v21 单侧脊线增强 → 标注/导出。

历史对比图展示同一采集序列三帧的原始 DSC、v21 自动和本版自动结果。两版各用自身自动参数，因此是整体显示结果对比，不是单独滤波的消融对比。`v21_to_v28.patch` 提供源代码差异。

这是独立的二维 DSC 校正、调色和标注程序，不再包含三维成像入口。

## 启动

- 最简单：双击 `启动超声校正工具.bat`。
- VS Code：双击 `UltrasoundImageCorrection.code-workspace`，按 F5，选择“运行二维超声校正 Image v28”。
- 也可运行 `python ultrasound_bin_gui.py`。

程序已经指向电脑上现有的 Python 环境，并检查 NumPy、Pillow 和 tkinter。

## 保留的 Image v16 基本功能

- 浏览一个采集目录，自动读取 `raw_frames_u8.bin`、`frames.json`、`scan.snp`、`integrity.json`。
- 自动读取帧数、扫描线数、采样点、探头、扇扫角、死区半径、采样尺度和逐帧扫描角。
- 四宫格实时预览：原图、DSC、DSC＋调色、DSC＋调色＋标注。
- 整组使用同一套 α、β、γ、白点、去散斑、原始细节混合和边缘参数。
- 红色整体亮区、蓝色强反声区、绿色主体边界。
- 自动主体识别、鼠标画笔标注及向连续帧传播。
- 骨骼声影显示补偿、PNG/BIN/参数 JSON 和 DSC 调色前后对比图导出。

## 沿用的 Image v21 改进（历史说明）

### 真轮廓旁残影

旧版宽尺度锐化会在真边缘旁形成明暗成对的轮廓。v21 改为单侧脊线增强：

1. 96% 细尺度、4% 宽尺度，仅用宽尺度维持连续性；
2. 只增强局部主亮脊，暗侧波瓣保留 6%；
3. 用平滑梯度判断连续轮廓，孤立散斑不会获得完整锐化；
4. 增强后限制在原始 3×3 邻域附近，最大外扩灰度由 7 降到 4。

自动边缘强度范围改为 1.45–1.65。样例第39帧中，锐化造成的暗侧变化像素从12,207降到87，约减少99.3%。

### 胎儿与子宫壁区分

- DSC 后对中央组织做很小的局部对比提升，保留内部不连通的灰色区域。
- 只压低扇区外围、明显高于邻域的反声亮斑，单像素最多降低16级；不删除子宫壁，也不修改原始文件。
- 主体自动种子增加中央位置权重并收紧到高可信区域，避免从外围子宫壁开始扩散。

### 标注避开边缘亮斑

- 红、蓝标线会忽略扇区外围约5.5%范围中的紧凑强反声亮斑。
- 绿色主体识别使用更保守的约9%外围安全带，并排除强反声亮斑。
- 安全带截断形成的边界不会被画成绿色，避免把子宫壁或扇区边界误当主体轮廓。

这些规则只影响显示增强和标线；校正后的灰度内容仍被保留。自动结果不是医学诊断分割，必要时请用画笔提供胎儿正样本。

## 建议参数

点击“自动（整组统一）”作为起点。手动调整时建议：

- α：1.00–1.20（自动模式会根据亮部细节下调）
- β：6–18
- γ：1.55–1.95
- Lee 去散斑：0.72–0.92，默认 0.80
- 双边滤波强度：0.30–0.55，默认 0.45
- 双边灰度相似尺度（归一化 log 域）：0.035–0.075，默认 0.06
- 原始细节混合：0.08–0.16，默认 0.10
- 边缘清晰度：1.20–1.65；仍有残影时先降到1.10–1.35
- 红线阈值：120–180
- 蓝线阈值：210–240
- 连续扩散：3–7
- 主体扩散：12–24

注意：显示增强和主体标注不可替代临床诊断或人工复核。
