# 胎儿 ROI U-Net 模型目录

把经过胎儿超声数据训练并导出的 `.onnx` 模型放在本目录，然后在程序的“机器学习胎儿 ROI”区域点击“浏览”选择模型。

程序支持常见输入：

- `[N,1,H,W]` 灰度 NCHW；
- `[N,3,H,W]` RGB NCHW；
- `[N,H,W,1]` 或 `[N,H,W,3]` NHWC；
- 固定尺寸或动态高度、宽度。

程序支持常见输出：

- 二分类 `[N,1,H,W]` 或 `[N,H,W,1]`；
- 多分类 `[N,C,H,W]` 或 `[N,H,W,C]`；
- 输出可以是概率，也可以是 logits。

二分类模型通常把“胎儿”作为唯一前景；多分类模型需要在界面填写训练时的胎儿类别 ID。输入归一化必须与训练配置一致，通常是 `0-1`。

本软件不附带未经验证的医学模型。通用 ImageNet、COCO 或自然图像预训练权重不能直接准确识别胎儿；必须在与你的探头、成像方式和标注规则相匹配的超声数据上训练，并使用独立病例验证 Dice、IoU、灵敏度和特异度。
